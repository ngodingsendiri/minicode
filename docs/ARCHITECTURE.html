Tiga lapisan logis, satu matriks ketergantungan. Semua sel "DILARANG" dijaga otomatis oleh test/ui-boundary.test.ts yang jalan di bun test — melanggar = CI merah, bukan sekadar gaya.

Lapisan logis ≠ struktur direktori. src/ui/ secara fisik ada di src/ tetapi bermain di L1 — lapisan ditentukan peran, bukan lokasi folder.
Satu-satunya jembatan UI ↔ agen. Data masuk UI lewat kontrak tipe struktural di src/ui/contract.ts (UiEvent, UiBus, UiStep, UiExecution, UiToolCallRef — EventBus kernel kompatibel struktural). Kemampuan agen masuk UI lewat callback yang di-inject dari composition root cli/setup.ts (contoh: ask untuk approval, setupWhenEmpty untuk wizard). UI tidak pernah menyentuh config, disk, atau kernel.
Pola DI yang sama berlaku di luar UI. Kebutuhan lintas-lapisan selalu disuntikkan dari composition root, bukan diimpor langsung: setSubAgentSessionFactory (cli/index.ts → delegate_task, supaya src/tools/ tidak mengimpor lapisan app), ask (approval), setupWhenEmpty (wizard). Tanpa injeksi, perilaku default selalu aman: deny / tolak jalan.
Subpath #minicore dideklarasikan di blok imports package.json (#minicore → vendor/minicore/src/core/index.ts, #minicore/* → subtree src kernel) — satu-satunya pintu kode ke L3.
Mengapa tiga lapisan? Kernel dapat disinkron/diganti tanpa menyentuh aplikasi; kebijakan keamanan berdiri di L2 sehingga otomatis berlaku untuk semua tool (bawaan maupun MCP); UI bebas berubah tanpa memengaruhi logika — dan sebaliknya.

02 Alur Eksekusi Satu Prompt

Tujuh tahap jalur utama, lengkap dengan file tempat tiap tahap hidup. Subcommand admin dan mode MCP server tidak lewat alur ini (lihat jalur samping diagram).

1
Entry & parsing cli/index.ts → cli/args.ts → cli/router.ts argv dipisah jadi flag & prompt; dispatch ke subcommand (auth/config/exec/mcp/pricing/providers/sessions/skills/stats) atau REPL. Flag tak dikenal tidak error — ia jadi kata prompt (§8).
2
Perakitan sesi cli/setup.ts → src/app/session.ts → src/app/{provider,tool,rag}-layer.ts Config dimuat; session kernel dibuat; provider + tools + permission dirakit; checkpoint & callback UI (ask, wizard) di-inject di sini — titik komposisi seluruh aplikasi.
3
Loop agen vendor/minicore/src/core/{session,loop}.ts session.run menjalankan executeTurn berulang (maxSteps default 50) di atas salinan ContextStore transaksional per turn — bisa di-rollback oleh checkpoint.
4
Streaming provider src/providers/router.ts → anthropic.ts · vendor openai-compat.ts Model dipilih, request dikirim, token di-stream sebagai event bus kernel → diterima presentation sebagai UiEvent.
5
Eksekusi tool vendor core/executor.ts → src/policy/executor.ts → src/tools/* Rantai gerbang §5: jail → permission → bash-guard → validateArgs → execute → truncation. Tool MCP eksternal dirutekan lewat src/mcp/client.ts dengan nama "serverid.toolname".
6
Rendering output src/ui/render/{sanitize,markdown,highlight,wrap,width}.ts → src/ui/assistant/simple.ts Teks tidak terpercaya disanitasi, didekorasi markdown, diukur dalam kolom, lalu mengalir append-only ke scrollback (printer linier, tanpa alternate screen). Assistant hanya mengonsumsi event UiBus — tidak memanggil agen langsung.
7
Persistensi src/session/{persistence,shadow-git,checkpoint}.ts · src/telemetry/trace.ts Pesan disimpan inkremental ke sqlite (WAL, TTL 30 hari); tree per turn dicatat shadow-git di refs/minicode/*; trace jsonl untuk diagnostik & statistik biaya.

04 Resep Ekstensi

Enam perubahan paling umum, tiap resep dengan titik sentuh file dan penjaga yang menjatuhkan CI bila dilewati.

Menambah tool bawaan L2

  1. Buat src/tools/nama.ts — ekspor objek Tool (type-only import dari #minicore).
  2. Daftarkan di array allTools pada src/tools/index.ts (impor + entri).
  3. Tambah test di test/; nama tool jadi kunci permission mode per-tool.
// src/tools/kalkulator.ts
import type { Tool } from "#minicore"
export const kalkulatorTool: Tool = {
  name: "kalkulator",
  description: "Hitung ekspresi aritmetika.",
  parameters: { type: "object",
    properties: { expr: { type: "string" } },
    required: ["expr"] },
  async execute(args, ctx) {
    ctx.signal.throwIfAborted()
    return String(hitung(args.expr))
  },
}
guard: hasil execute otomatis dipotong sesuai LIMITS; jangan mengimpor src/ui; operasi file wajib lewat cek jail.

Menambah subcommand admin L1

  1. Buat cli/commands/nama.ts dengan handleNama(args, …).
  2. Daftarkan rute di cli/router.ts (dispatch).
  3. Update blok HELP + daftar flag di cli/index.ts.
guard: subcommand tidak masuk loop agen; akses config hanya lewat API src/config.ts & src/providers/provision.ts, bukan baca file mentah.

Menambah slash command REPL L1

  1. Registry builtin di cli/commands.ts — tambah entri + handler.
  2. Butuh data agen? Ambil lewat callback/session yang sudah di-inject, bukan impor kernel di UI.
  3. Skill eksternal? Cukup letakkan berkas skill — dimuat src/skills/loader.ts tanpa ubah kode.
guard: output slash tetap harus lewat sanitizeAnsi + width.ts seperti teks model.

Menambah provider / endpoint L2

05 Rantai Pemeriksaan Tool Call

Setiap tool call melewati gerbang berurutan; gagal di satu gerbang = ditolak, tidak lanjut.

1 · Jail universalRealpath di luar root & path sensitif ditolak sebelum dispatch mode. Selalu aktif di semua mode.src/policy/jail.ts
→
2 · Mode izinauto / ask / readonly / plan / allowlist / allow-all.src/policy/permission.ts
→
3 · Bash-guardNormalisasi & pemeriksaan statik perintah bash.src/policy/bash-guard.ts
→
4 · validateArgsValidasi argumen per skema tool.vendor core/executor.ts
→
5 · Execute & truncateHasil dipotong sesuai LIMITS sebelum kembali ke konteks.src/policy/executor.ts
Urutan normalisasi bash-guard: stripQuotes → inlineSimpleVars → stripCommandWrappers → inspectBashCommand. Perintah dinormalisasi terlebih dahulu supaya bypass lewat quoting/variabel/wrapper ketahuan; jangan memanggil inspectBashCommand pada string mentah.
Pengecualian by-design: mode allow-all sengaja melewati gerbang 3 (bash-guard) — kepercayaan penuh pada user. Gerbang 1 (jail universal) tetap berlaku untuk semua mode, termasuk allow-all. Regresinya dijaga bun run gate:bash.

08 Invarian Struktural

Aturan tak tertulis yang kalau dilanggar menghasilkan bug yang sudah pernah terjadi di repo ini.

  • Bun-only, zero runtime deps. bin menunjuk langsung cli/index.ts; tidak ada build step. dependencies package.json kosong dan harus tetap kosong.
  • Kernel beku. vendor/minicore hanya berubah lewat seam aditif + bun run vendor:minicore; aplikasi tidak pernah menulis ke dalam vendor.
  • Batas lapisan itu kode, bukan harapan. Matriks §1 dieksekusi sebagai test (test/ui-boundary.test.ts) — tambah modul baru berarti periksa ulang arahnya.
  • Teks tak terpercaya → sanitizeAnsi. Output model, hasil tool, dan isi berkas wajib disanitasi sebelum render; tanpa itu model bisa membersihkan layar atau keluar alternate screen.
  • Lebar diukur dalam kolom. Pakai displayWidth/truncateToWidth/padToWidth (src/ui/render/width.ts), bukan .length/.slice() — CJK & emoji 2 kolom.
  • c & glyphs adalah getter di src/ui/render/theme.ts yang membaca state runtime (dukungan UTF-8, NO_COLOR; palet tunggal sejak fitur tema dihapus). Menyimpannya ke const module scope membekukan nilai saat import — jebakan yang sudah tiga kali terulang.
  • Flag tak dikenal = kata prompt. cli/args.ts hanya mengenali whitelist flag; --typo tidak error tetapi ikut masuk teks prompt (args.ts:62). Tambah flag baru = daftarkan di whitelist.
  • Jail mendahului segala mode. Tidak ada jalur eksekusi tool yang boleh mem-bypass src/policy/jail.ts, termasuk allow-all dan tool MCP.
  • Tool tidak mengimpor lapisan app/sesi. Kebutuhan lintas-lapisan (mis. sesi sub-agen untuk delegate_task) disuntikkan dari composition root via setter DI; tanpa injeksi tool fail-closed. Arah providers → config juga satu arah sejak provisioning dipisah ke providers/provision.ts.
  • Output shell-first. Tidak ada alternate screen (?1049h), tidak ada redraw penuh, tidak ada modal overlay: output mengalir append-only ke scrollback dan scrollback adalah satu-satunya transcript. Tool call compact di REPL (satu baris ✓ nama target); expanded tersedia via env//compact/verbose. UI ekran (manager/wizard/picker) transient — menghapus diri sendiri, tidak menyentuh scrollback.
  • Kontrak terminal FROZEN. docs/TERMINAL_CONTRACT.md membekukan klasifikasi writer, contract stdout/stderr, dan 12 invariant terminal (§9) — wajib dibaca sebelum menyentuh output/rendering; setiap perubahan perilaku wajib update dokumen + test peta proteksinya.
  • Satu arbitrase transient. Semua painter stderr (garis turn, wizard spinner) lewat acquireTransientPaint/paintWrite di src/ui/runtime/statusline.ts; tulis asing non-UI saat painter aktif dikomit sebagai baris permanen — tidak hilang, tidak merusak transient.
  • Non-TTY = polos. Pipe/redirect/CI tidak boleh mengandung cursor control, animasi, atau warna (warna digate stdout.isTTY; NO_COLOR menang).
  • Peta ini harus hidup. Setiap perubahan struktur (tambah/hapus/pindah modul atau lapisan) WAJIB memperbarui docs/ARCHITECTURE.html dalam perubahan yang sama — lihat AGENTS.md.
Minicode · Peta struktur hidup — terminal contract FROZEN (docs/TERMINAL_CONTRACT.md) · peta ini menyertakan panduan UI/UX untuk developer (§9).

09 UI/UX untuk Developer — Rendering Terminal

Ringkasan kontrak output yang menjaga MiniCode tetap shell-native: lima primitif tampilan, dua stream dengan peran tetap, satu arbitrase transient. Versi lengkap + residual risk yang disengaja ada di docs/TERMINAL_CONTRACT.md (FROZEN); panduan pengguna di docs/USAGE.md.

1 · Prompt

minicode <mode> › — baris input interaktif + dropdown slash; satu-satunya elemen "hidup" saat idle.

2 · Pesan model

Streaming ke stdout, di-sanitasi, dibungkus per baris mengikuti kolom terminal; fence markdown indent 2 spasi.

3 · Aktivitas

Garis transient di stderr (TTY saja): "Thinking" atau · nama-tool target selama tool berjalan. Hilang saat teks mengalir.

4 · Hasil tool

Ledger stderr, compact: ✓ nama target satu baris (tanpa bocor isi file); error ✗ nama: pesan. Expanded/verbose menampilkan isi.

5 · Error

✗ pesan actionable — sekali per kegagalan via takePendingError(); tidak pernah dump JSON/stack ke user.

Stream contract

stdout = output program (teks model, receipt). stderr = progress/diagnostik. Non-TTY: 0 ANSI, 0 spinner, 0 cursor control.

Transient rendering memiliki satu ownership mechanism (src/ui/runtime/statusline.ts):

Ownership

Painter garis turn (turn) dan wizard spinner (spinner) klaim via acquireTransientPaint(kind); semua tulis painter lewat paintWrite.

Foreign writers

Diagnostik non-UI (router/providers/tool warnings) boleh menulis mentah ke stderr — arbitrator mengkomitnya sebagai baris permanen saat painter aktif.

Lifecycle tertutup

Garis tidak pernah stale: endTurn() dipanggil driver setelah setiap session.run settle (kernel hanya emit turn:completed di jalur sukses).

Mutual exclusion

Painter vs spinner secara desain disjoint; overlap memicu signal [transient-paint] … sekali per pasangan (bukan crash).
