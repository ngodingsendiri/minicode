01 Tiga Lapisan

Aturan arah: lapisan atas boleh memakai lapisan bawah; tidak pernah sebaliknya. Kernel tidak mengimpor apa pun dari luar vendor/.

1
CLI & TUI L1
cli/ · src/tui/
Semua yang menyentuh terminal: argv, REPL, picker, wizard, tema, rendering. Tidak ada logika agen di lapisan ini.
▼ memakai
2
Agen Minicode L2
src/
Perakit sesi (app/), keamanan & izin (policy/), 31 tool, provider, MCP/LSP, hooks, memory, skills, persistensi sesi.
▼ lewat #minicore
3
Kernel MiniCore L3
vendor/minicore/ · pin 1eceea9e
Loop agen inti. Beku: hanya seam aditif yang boleh diubah (compactAsync, initialMessages); sinkron via bun run vendor:minicore.
Lapisan logis ≠ struktur direktori. src/tui/ secara fisik berada di src/ tetapi milik L1 — lapisan ditentukan oleh peran, bukan oleh lokasi folder.
Subpath #minicore dideklarasikan di blok imports package.json — satu-satunya pintu masuk kode ke kernel.
Mengapa tiga lapisan? Kernel dapat diganti/disinkron tanpa menyentuh aplikasi; kebijakan keamanan berdiri di L2 sehingga berlaku untuk semua tool; TUI bebas berubah tanpa memengaruhi logika.

02 Alur Eksekusi Satu Prompt

Tujuh tahap jalur utama. Subcommand admin dan mode MCP server tidak lewat alur ini (lihat jalur samping diagram).

1
Entry & parsing cli/index.ts → cli/args.ts → cli/router.ts argv dipisah jadi flag & prompt; dispatch ke subcommand (auth/config/exec/mcp/pricing/providers/sessions/skills/stats) atau REPL.
2
Perakitan sesi cli/setup.ts → src/session.ts → src/app/{provider,tool,rag}-layer.ts Config dimuat; session kernel dibuat; provider + tools + permission dirakit; checkpoint disambungkan.
3
Loop agen vendor/minicore/src/core/{session,loop}.ts session.run menjalankan executeTurn berulang (maxSteps 50) di atas salinan ContextStore transaksional per turn.
4
Streaming provider src/providers/router.ts → anthropic.ts / vendor openai-compat.ts Model dipilih, request dikirim, token di-stream sebagai event bus kernel.
5
Eksekusi tool vendor core/executor.ts → src/policy/executor.ts → src/tools/* runCall: permission → validateArgs → execute → truncation hasil. Tool MCP dirutekan lewat src/mcp/client.ts.
6
Rendering output src/tui/{sanitize,markdown,highlight,wrap,width}.ts → minimal/fullscreen.ts Teks tidak terpercaya disanitasi, didekorasi markdown, diukur dalam kolom, lalu digambar ke terminal.
7
Persistensi src/session/{persistence,shadow-git,checkpoint}.ts · src/telemetry/trace.ts Pesan disimpan inkremental ke sqlite (WAL, TTL 30 hari); tree per turn dicatat shadow-git; trace jsonl untuk diagnostik.

04 Rantai Pemeriksaan Tool Call

Setiap tool call melewati gerbang berurutan; gagal di satu gerbang = ditolak, tidak lanjut.

1 · Jail universalRealpath di luar root & path sensitif ditolak sebelum dispatch mode. Selalu aktif di semua mode.src/policy/jail.ts
→
2 · Mode izinauto / ask / readonly / plan / allowlist / allow-all.src/policy/permission.ts
→
3 · Bash-guardNormalisasi & pemeriksaan statik perintah bash.src/policy/bash-guard.ts
→
4 · validateArgsValidasi argumen per skema tool.vendor core/executor.ts
→
5 · Execute & truncateHasil dipotong sesuai LIMITS sebelum kembali ke konteks.src/policy/executor.ts
Pengecualian by-design: mode allow-all sengaja melewati gerbang 3 (bash-guard) — kepercayaan penuh pada user. Gerbang 1 (jail universal) tetap berlaku untuk semua mode, termasuk allow-all.

06 Invarian Struktural

  • Bun-only, zero runtime deps — bin menunjuk langsung cli/index.ts; tidak ada build step.
  • Kernel beku — vendor/minicore hanya boleh diubah lewat seam aditif; sinkron via bun run vendor:minicore.
  • Teks tak terpercaya → sanitizeAnsi — output model/tool/berkas wajib disanitasi sebelum render.
  • Lebar dalam kolom — gunakan displayWidth/truncateToWidth, bukan .length/.slice().
  • c & glyphs adalah getter — jangan simpan ke const module scope; nilai dibekukan saat import.
  • Gate — bun x tsc --noEmit && bun run lint && bun test && bun run gate:coverage && bun run gate:pack.
